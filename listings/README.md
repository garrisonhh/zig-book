# Code Listings

You can find working code for code listings here. This may differ in minor ways from the MEAP text, if I find errata they will be fixed here.

I aim to compile and test as many self-contained code listings as possible. This almost exclusively applies to chapters 1 through 4, as later chapters are almost entirely project based -- project code is provided elsewhere.

You can build everything with `zig build`, or try `zig build --help` to build or test a specific chapter or listing.
